# Nexo Digital Web

Sitio web estático del proyecto de puente basculante hidráulico de Nexo Digital (HTML, CSS y JavaScript).

## Estructura
- `index.html`, `mision-vision.html`, `proyecto.html`, `contacto.html`, `boceto.html`
- `styles.css` y `app.js`
- `assets/` con `logo.png`, `hero.jpg` y las fotos y esquemas del proyecto

## Publicar con GitHub Pages
Settings > Pages > Branch `main` y carpeta `/ (root)` > Save.
